=head1 NAME

bash/utils-base - helper functions for shell scripts

=head1 SYNOPSIS

  source bash/utils-base

=head1 DESCRIPTION

This library provides small utility functions for basic type checks, shell flag
inspection, array manipulation, diagnostic messages, and list handling.

=head1 FUNCTIONS

=over 4

=item B<is_digit>

Return success if the argument is a single decimal digit 0 through 9.
Input is the argument; output is the shell return status,
which is 0 on success and non-zero otherwise.

=item B<is_number>

Return success if the argument is an integer value (as accepted by shell arithmetic
comparison).
Input is the argument; output is the shell return status.

=item B<is_alpha>

Return success if the argument is composed only of ASCII letters A-Z or a-z.
Input is the argument; output is the shell return status.

=item B<warnx> $message

Print I<message> to stderr prefixed with the current script name,
while preserving multiline output one line at a time.
Input is one or more arguments that are concatenated to a single message string;
output is written to stderr.

=item B<errx> $code $message

Mimic C<errx(3)> by printing I<message> to stderr and then exiting with the given status I<code>.
Input is an integer exit status code followed by message text;
output is diagnostic text to stderr.

=item B<bash_isset> $mask [$shellopts]

Return the subset of characters from I<mask> that are present in the shell
option string I<shellopts> (default: C<$->).
The result is printed to stdout.
It's a single underscore if no matches are found.

=item B<bash_defined> $varname

Return success if the variable named by the argument exists in the current
shell environment.
Input is the variable name; output is the shell return status.

=item B<errorlevel> $code

Simply return the numeric status I<code> passed in the argument.
Useful to set C<$?> without actually exiting a function/script.

=item B<bash_join> $delimiter ${items[@]}

Join I<items> with the given I<delimiter> and print the result on stdout.
When the separator is a single character, it temporarily sets C<IFS> for the join operation.

=item B<in_list> $needle ${haystack[@]}

Return success if I<$needle> found in the supplied I<$haystack> list.

=item B<array_shift> I<array_variable_name>

Return the first element from the named indexed array,
remove it from the array,
and reindexing the remaining entries.
Input is the array variable's name;
output is the first (removed) element printed on stdout.
It modifies the named array in place.

=item B<array_reverse> I<array_variable_name>

Reverse the elements of the named indexed array in place.
Input is the array variable's name;
output is none.
It depends on the named array existing.
Mutates that array by swapping pairs of elements.

=back

=cut
