=head1 NAME

bash/utils-cache - associative-array cache helpers for bash

=head1 SYNOPSIS

  source bash/utils-cache

=head1 DESCRIPTION

This library provides a small file-backed associative-array cache for bash
scripts. It loads a tab-separated key/value file into a global associative
array, retrieves values by key, and appends updates back to the backing file.

=head1 FUNCTIONS

=over 4

=item bash_cache_init($global_var, $cachefile)

Initialize a global associative array named C<$global_var> and bind it to the
cache file at C<$cachefile>. Input is the variable name and the cache file path;
output is the shell return status (success is 0 if already initialized or just
set up). On initialization, it creates a C<${global_var}_file> variable holding
the cache path and loads any existing tab-separated entries from the file into
the associative array.

=item bash_cache_retrieve($global_var, $key, $output_var)

Look up a key in the named associative array and assign its value to the
variable named by C<$output_var>. Input is the global array name, the lookup
key, and the target variable name; output is written to that variable, or the
function returns 1 when the key is absent. It depends on the array being
initialized and does not modify any other globals.

=item bash_cache_set($global_var, $key, $value)

Store a value under a key in the named associative array and append a
C<key<TAB>value> line to the backing cache file. Input is the array name, the
key, and the value; output is none. It also creates the parent directory for
the cache file if needed and sets the global associative array entry.

=back

=cut
