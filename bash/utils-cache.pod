=head1 NAME

bash/utils-cache - helpers to cache single line text for bash

=head1 SYNOPSIS

  source bash/utils-cache

=head1 DESCRIPTION

This library provides a small file-backed associative-array cache for bash
scripts. It loads a tab-separated key/value file into a global associative
array, retrieves values by key, and appends updates back to the backing file.

=head1 FUNCTIONS

=over 4

=item B<bash_cache_init> $global_var_name $cachefile_path

Initialize a global associative array named by the name passed by I<$global_var_name> argument
and load up from the file specified by I<$cachefile_path> argument.
On initialization, it creates an also global variable named like C<${global_var_name}_file>,
which holds I<$cachefile_path>.
If invoked like, for example, C<bash_cache_init CACHED_DATA /var/cache/data>,
it sets C<$CACHED_DATA_file> to C</var/cache/data>.

=item B<bash_cache_retrieve> $global_var_name $key $output_var_name

Look up I<key> in the named associative array and assign its value to the
variable named by I<output_var_name>.
Returns 1 when the key is absent.
It depends on the array being initialized by B<bash_cache_init>.

=item B<bash_cache_set> $global_var_name $key $value

Store a value under I<key> in the named associative array
and append a C<< key<TAB>value >> line to the backing cache file.
Creates the cache file if not exists.
See B<bash_cache_init> to initialize I<global_var_name> array.

=back

=cut
