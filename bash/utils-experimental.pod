=head1 NAME

bash/utils-experimental - bash helper functions, experimental stage

=head1 SYNOPSIS

  source bash/utils-experimental

=head1 DESCRIPTION

This library contains a few convenience helpers for script authors.

=head1 FUNCTIONS

=over 4

=item B<fixerrexit> I<COMMAND...>

Run the supplied command in a subshell while preserving the current C<errexit>
setting in the parent shell.
Return with the I<COMMAND>'s exit status.

=item B<bash_scriptdir>

Return the directory path of the currently executing script on stdout,

=item B<ECHO>

Print the argument to stdout without adding a trailing newline.

=item B<bash_assign_global> I<NAME_1> [I<NAME_2> [...]] -- I<VALUE_1> [I<VALUE_2> [...]]

Create or replace one or more globals with the given values.
Input is a list of variable names followed by a literal C<--> and values.
It assigns I<VALUE_1> (I<VALUE_2> and so on) values
to global variable(s) I<NAME_1> (I<NAME_2> and so on, respectively).
If there are more I<< VALUE_Z<>B<n> >> arguments than I<< NAME_Z<>B<n> >>,
then the unmatched ones are ignored.

=item B<bash_assign_global_greedy> I<NAME_1> [I<NAME_2> [...]] -- I<VALUE_1> [I<VALUE_2> [...]]

Same as B<bash_assign_global>, except if there are more I<< VALUE_Z<>B<n> >> arguments
than I<< NAME_Z<>B<n> >>, then appends the remaining values to the last I<NAME_z> variable
with the first char of C<IFS> as joiner.

=back

=cut
