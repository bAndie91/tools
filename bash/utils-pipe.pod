=head1 NAME

bash/utils-pipe - anonymous file-descriptor pipe helpers

=head1 SYNOPSIS

  source bash/utils-pipe

  pipe read_fd write_fd
  echo Lorem ipsum >&$write_fd
  read -u $read_fd data

=head1 DESCRIPTION

This library implements anonymous pipe creation and simple file descriptor
management for bash scripts. It can create a reader/writer pair, close one or
more descriptors, and capture stdout/stderr separately without running the
command twice.

=head1 FUNCTIONS

=over 4

=item B<pipe> I<reader_var_name> I<writer_var_name>

Create an anonymous pipe and store the read end and write end file descriptors
in variables named by the supplied arguments.
Both variables are assigned numeric file descriptor values.
The implementation uses /proc and helper sleep processes to acquire the pipe ends.

=item B<close> I<FD> [I<FD> [...]]

Close the file descriptors supplied in arguments.
Example:

  close 60 11 $writer_fd

=item B<capture2> I<COMMAND> [I<ARG> [I<ARG> [...]]]

Run I<COMMAND> while capturing stdout and stderr into the script-global
variables: B<capture2_stdout> and B<capture2_stderr>.
Return status is I<COMMAND>'s return status.
It depends on C<pipe> and C<close>.

=back

=cut
