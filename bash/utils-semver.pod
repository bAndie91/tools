=head1 NAME

bash/utils-semver - compare canonical semver-like version strings

=head1 SYNOPSIS

  source bash/utils-semver

  version_compare 1.2.3 1.2.4

=head1 DESCRIPTION

This library helps normalize and compare version strings using sort-based,
version-aware ordering. Useful for semantic- and release-version comparisons.

=head1 FUNCTIONS

=over 4

=item B<canonize_semver> $version_string

Return the canonical version string by removing trailing C<.0> segments from the input.
Input is a version string; output is the normalized version printed on stdout.

=item B<version_compare> $ver_a $ver_b

Compare two version strings and return 
0 when equal, 
1 when C<$ver_a> is greater than C<$ver_b>, and
255 when C<$ver_a> is less than C<$ver_b>.

=item B<version_is_lesser> $ver_a $ver_b

Return success when C<$ver_a> is less than C<$ver_b> according to semantic version ordering.

=item B<version_is_greater> $ver_a $ver_b

Return success when C<$ver_a> is greater than C<$ver_b> according to semantic version ordering.

=item B<version_is_greater_or_equal> $ver_a $ver_b

Return success when C<$ver_a> is greater than or equal to C<$ver_b> according to semantic version ordering.

=item B<version_is_lesser_or_equal> $ver_a $ver_b

Return success when C<$ver_a> is less than or equal to C<$ver_b> according to semantic version ordering.

=back

=cut
