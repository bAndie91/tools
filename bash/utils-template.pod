=head1 NAME

bash/utils-template - template substitution for shell values

=head1 SYNOPSIS

  source bash/utils-template

  template input.tmpl > output.txt

=head1 DESCRIPTION

This library reads text from files or stdin and replaces template tokens in the
form C<%NAME%> with the value of the shell variable named by C<NAME>.

=head1 FUNCTIONS

=over 4

=item B<template> [I<PATH> [I<PATH> [...]]]

Read each input file I<PATH> (or stdin if no files are given) and expand C<%VAR%>
placeholders using the current shell variable values.
Output the substituted text to stdout.

=back

=cut
