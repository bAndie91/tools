=head1 NAME

bash/utils-try - try/except style shell error handling

=head1 SYNOPSIS

  source bash/utils-try

  try --except 'echo failed'
  ...
  untry

=head1 DESCRIPTION

This library provides a small stack-based emulation of a try/except block in bash.
It saves the current error-trap and errexit/errtrace settings before
turning them on for the guarded code, then restores the previous state with
C<untry> when the block is complete.

=head1 FUNCTIONS

=over 4

=item B<bash_trapbody> $signal

Return the current trap body for the named signal,
or a single hyphen when no trap is set.
Input is the signal name; output is printed to stdout.

=item B<try> [--except I<COMMAND>]

Begin a try region by saving the current shell B<errexit> and B<errtrace> settings and B<ERR> trap
in a global scalar variable called C<TRYSTACK>.
The B<--except> option sets I<COMMAND> as the B<ERR> trap handler

=item B<untry>

Restore the shell state saved by the most recent B<try> call
and pop C<TRYSTACK>.
It restores the previous C<errexit>, C<errtrace>, and B<ERR> trap values.

=back

=cut
